CONSOLE MAP ERROR FIX
---------------------
Navigation Test 1 repeatedly raised:

Navigation/MapPins.lua:94: function expected instead of nil

The error came from our optional map tooltip callback calling pin:GetTag().
LibMapPins/ESO map pins expose GetPinTypeAndTag(), not GetTag().

Because this navigation test does not need hover tooltips, the safest console
fix is to remove the tooltip callback completely rather than introduce more
PC-style map tooltip handling.

The repeated references to mouseover/cursorPosition in ESO's stack trace are
internal WorldMap manager names. Gamepad map focus still travels through that
shared map-tooltip path; no physical mouse is required. The gerbils are safe.
