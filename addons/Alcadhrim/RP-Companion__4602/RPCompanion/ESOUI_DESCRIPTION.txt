RP Companion is an immersive roleplay addon for The Elder Scrolls Online.

Features:
- Complete character profile
- Long editable biography
- Currently and appearance fields
- Alignment system: Lawful ↔ Chaotic and Good ↔ Evil
- Morality scale
- RP journal
- Encounter log
- Multiple profiles
- Network tab
- RP profile sharing
- RP inspection through whisper-based profile exchange
- LibAddonMenu-2.0 settings panel

Designed for roleplayers and RP communities who want a lightweight, in-game character profile system.

Required dependency:
- LibAddonMenu-2.0

Commands:
- /rp help
- /rp ui
- /rp show
- /rp inspect
- /rp share <@UserID>
- /rp inbox
