Version 1.0.61

- Added an Update interval setting slider.
- The fallback UI refresh interval can now be adjusted from 100 ms to 2000 ms.
- Default remains 1000 ms to keep the current lightweight behavior for users who prefer it.
- Lower values can make the UI catch up faster after opening or closing other UI panels.


Version 1.0.60

- Fixed Ultimate identity color following while keeping the original current/inactive bar display behavior.
- Color baseline now uses the actual ESO primary/main-hand Ultimate as amber and backup Ultimate as violet.
- Fixed the issue where reloading UI on the backup bar could teach the wrong Ultimate color.
- Back panel default color remains violet instead of cyan.

Sora Ultimate Pair

Sora Ultimate Pair displays front-bar and back-bar Ultimate information in a compact custom UI.
