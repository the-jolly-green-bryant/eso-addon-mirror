Screenshot Mode - by Stacy5419
based on the Screenshot Helper addon by sirinsidiator

Screenshot Mode adds:

- Key binding in Controls/Addon Controls that allows you disable/enable all hud elements and markers with the press of a single button.
- Key binding to toggle the UI, take a screenshot and re-toggle the UI with the press of a single button.

To install this addon, copy the ScreenshotMode folder into your ESO addons directory.

To use this addon, goto your control settings in game and bind a key to Screenshot Mode. Pressing the key in game will disable/enable all hud elements and markers, making it easier to take screenshots.
