# README #

This addon picks a random vanity pet from your collection -- for those moments when you just can't decide which one to display. Now includes the "/randompet" command to swap pets on demand!

### Who is responsible for this? ###

* joshfong

### How can I help? ###

First of all, feedback is always welcome. Bug reports, feature requests, you name it. I want to make this the best it can be. Second, translations are always welcome! If you'd like to help out with that, PM me and we'll get your translation integrated.
