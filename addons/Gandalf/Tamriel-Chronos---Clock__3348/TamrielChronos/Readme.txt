To intall Chronos, two steps are needed:

1. Step
   To install move the folder "TamrielChronos" into your ESO addon folder:
   -> Documents\Elder Scrolls Online\live\AddOns\TamrielChronos
      If you installed Chronos successfully, the addon manifest path 
      look like this:
      ...\Documents\Elder Scrolls Online\live\AddOns\TamrielChronos\TamrielChronos.txt

2. Step
   Chronos depends on the library "LibAddonMenu2.0".
   If it is not already installed, use Minion to install it or 
   download/install it from 
   "https://www.esoui.com/downloads/info7-LibAddonMenu.html"
