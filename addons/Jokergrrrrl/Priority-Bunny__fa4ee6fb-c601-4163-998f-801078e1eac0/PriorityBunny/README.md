# Priority Bunny 0.4.0 — Console

Required add-ons:
- LibAddonMenu-2.0
- LibGamepad

Harven's Addon Settings is NOT required.

## How to identify this build
Open Settings > Addons > Priority Bunny.
The first line must say:
YOU ARE RUNNING PRIORITY BUNNY 0.4.0

The sections must say:
BAR 1
BAR 2
NOW ALERT

If you still see FRONT BAR / BACK BAR, Xbox is loading an older copy.

## NOW test
Press TEST NOW ALERT in the settings panel.
It should immediately show a large:
NOW! PRIORITY 1

This test is independent of skill timers. If the test works but real skills do
not trigger, the visual alert is fine and timer detection is the part to fix.

## Fresh settings
0.4.0 uses PriorityBunnySavedVariablesV4 so old settings/library data cannot
contaminate this build. Priorities must be assigned again once.
