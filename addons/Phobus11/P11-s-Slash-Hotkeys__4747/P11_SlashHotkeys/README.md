# P11_SlashHotkeys

Allows the user to set hotkeys for standard chat topics such as guild recruiting.

## Features

- Bind keys to instantly send preset slash-command chat text (e.g. guild recruiting spam,
  trade-channel ads).
- Up to 10 configurable slash-hotkey slots.
- Settings scope (Character / Account / Server-wide) is chosen per-player at runtime via the
  in-game settings panel, powered by [LibExtendedSavedVars](https://www.esoui.com/downloads/info3134-LibExtendedSavedVars.html).

## Requirements

- [LibAddonMenu-2.0](https://www.esoui.com/downloads/info7-LibAddonMenu.html) >= 43
- [LibExtendedSavedVars](https://www.esoui.com/downloads/info3134-LibExtendedSavedVars.html) >= 104

## Installation

1. Install the dependencies above if you don't already have them.
2. Extract this addon's folder into your `live\AddOns\` directory.
3. Enable it (and its dependencies) from the in-game Addons menu.

## Configuration

Open the addon's settings panel from ESO's Settings > Add-Ons menu (listed as **Slash Hotkeys**)
to bind keys, edit the chat text sent by each slot, and choose the settings scope.
