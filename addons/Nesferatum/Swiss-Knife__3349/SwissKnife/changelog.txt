v.0.79.0: Изменения версии
  - Добавлен функционал сбора писем с ресурсами (от наемников или отправленных с другого аккаунта через SKMail). Сбор
    осуществляется при входе в окно почты, пустые письма удаляются.
    По умолчанию функционал отключен. За включение отвечают две опции: первая - `Получать письма наемников` - включает
    получение ресурсов из писем наемников, вторая опция - `Получать письма автоматически` - отвечает за получение писем
    пересланных через SKMail, данная опция находится в блоке настройки адресата для ресурсов.
    Также есть дополнительные настройки:
      `Только при наличии подписки` - по умолчанию включена, ограничивает автоматическое получение ресурсов, если
    подписка не активна;
      `Перезапускать получение после сбоя` - по умолчанию включено, позволяет повторно попытаться получить или удалить
    письмо при ошибке или таймауте;
      `Количество попыток` - сколько раз пытаться повторить получение письма, после того, как попытки исчерпаны, письмо
    будет пропущено и начато получение следующего письма из очереди;
      `Время ожидания получения письма, мс` - таймаут между попытками получения письма.
      Экспериментально установлено, что при 3 попытках и интервале 1500мс письма гарантировано собираются, хотя общее
    время сбора значительно увеличивается. При 5 попытках и интервале 500мс время сбора сокращается, но сбор
    осуществляется все еще гарантировано. Минимальный порог интервала 250мс, иначе сервер может банить запросы и письма
    перестают собираться, при этом значении таймаута должно быть установлено 8-10 попыток. Это самый быстрый вариант
    сбора, но он зависит от пинга до сервера и его загруженности. По умолчанию установлено соотношение 5/500, как
    оптимальное.

v.0.78.0: Изменения версии
  - Добавлен функционал обработки глифов и предметов с особенностью `Intricate (Мастерство)` для
    прокачки профессий. Механизм работы такой: если получен предмет, который может быть использован для
    прокачки какой-либо крафтовой профессии - выполняется проверка, если уровень персонажа в этой
    профессии не достиг максимума - предмет помечается пометкой `Деконструкция` при помощи FCOIS
    и при заходе в соответствующий крафтовый станок предмет разбирается.
      Если уровень профессии уже на максимуме, то есть два варианта работы с предметами для прокачки
    профессии. Можно включить отправку предметов в хлам. Или же через SKMail настроить отправку
    их на другой аккаунт.
      За этот функционал отвечают несколько настроек из раздела `Добыча`. Включаются он через настройки
    `Использовать глифы для прокачки профессий` и `Использовать `Intricate` для прокачки профессий`.
    При обоих этих опциях появляется возможность включить отправку в хлам через настройку `В хлам, если
    уровень профессии максимальный`. Также у глифов есть настройка максимального качества, которое можно
    использовать. Для отправки `Intricate` предметов или глифов на другой аккаунт используется раздел
    `Почта`
  - Для обеспечения функционала прокачки профессий была добавлена возможность автоматической разборки
    глифов на станциях.
  - Была добавлена возможность настроить отправку глифов на другой аккаунт, для этого появился
    соответствующий блок в разделе `Почта`.
  - При включенном автоматическом разборе предметов помеченных для деконструкции, после разбора
    всех предметов окно станции теперь закрывается автоматически.
  - Сортировка инвентаря из контекстного меню `SKAuto: Бесполезное` теперь затрагивает и предметы
    для прокачки профессий.

v.0.65: Изменения версии
  - Добавлена возможность использования общих настроек на все аккаунты в которые осуществляется
    вход с данного компьютера. При включении данной опции происходит копирование всех настроек
    и всех списков отслеживаемого (удаляемые предметы, бесполезные сеты...) текущего профиля
    в общие настройки всех аккаунтов. Если опция уже включена или включалась ранее - копирование
    не производится.
       Рекомендуется первый раз включать данную опцию на том аккаунте или персонаже настройки
    которого вы хотите сделать общими. Если ранее были включены общие настройки на аккаунт,
    то будут скопированы они, если включены индивидуальные настройки на каждого персонажа,
    то скопированы будут настройки текущего персонажа.
       После включения данной опции и перезагрузки интерфейса есть возможность дополнить списки
    отслеживаемого импортировав их из какого-то конкретного персонажа аккаунта или из общих
    настроек аккаунта. Импорт доступен в настройках аддона в разделе добыча и срабатывает сразу
    после выбора в выпадающем списке источника для импорта. Список источников для импорта состоит
    из имен всех персонажей аккаунта, также туда добавлен элемент с названием аккаунта для импорта
    списков из общих на данный аккаунт настроек.
       Работает импорт следующим образом - если элемент импортируемого списка отсутствует в текущем
    списке - он туда добавится, если элемент уже есть - импортируемый элемент заменит имеющийся
    в текущем списке со всеми параметрами (например, настройки отслеживаемого комплекта заменятся
    на те, что находятся в импортируемом списке). Выполнив по-очереди импорт из всех источников - можно
    слить все списки аккаунта вместе. Зайдя в другой аккаунт можно повторить процедуру и тем самым слить
    все списки всех аккаунтов в общие.
       Если изначально на всех аккаунтах было включено использование настроек на аккаунт, то достаточно
    на одном из них включить общие настройки на все аккаунты, потом по-очереди зайти во все остальные
    аккаунты и импортировать списки из общих настроек, по одному импорту на каждый аккаунт, за исключением
    первого.

    выполняет фильтрацию всех предметов инвентаря на принадлежность к отслеживаемым предметам
    и комплектам, при соответствии критериям: предмет из списка удаляемых - уничтожается,
    предмет из отслеживаемых комплектов из списка хлама - помечается как хлам.
