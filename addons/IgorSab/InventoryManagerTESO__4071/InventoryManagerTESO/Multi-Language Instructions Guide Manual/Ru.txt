InventaryManagerTESO:

InventaryManagerTESO — это аддон для управления инвентарём в The Elder Scrolls Online, который добавляет удобное окно с расширенными функциями сортировки, фильтрации, категоризации и управления предметами. Вот полный перечень его возможностей:

    Улучшенное окно инвентаря
    Отображает до 200 предметов в сетке 10×20 (44×44 пикселя на ячейку).
    Показывает иконки предметов, их количество в стеке, а также визуальные индикаторы (например, галочки для выделения и затемнение для заблокированных предметов).
    Отображает общее количество занятых и доступных слотов в сумке (например, "125/200").
    Показывает количество золота персонажа с форматированием (например, "1 860 657").
    Сортировка предметов
    По умолчанию: Сортировка по категориям (оружие, броня, расходуемые предметы, ремесленные материалы и т.д.) с учётом приоритета (например, заблокированное снаряжение выше, чем еда).
    Возможность переключения направления сортировки (прямой или обратный) при повторном нажатии на кнопку сортировки.
    Кнопка "All" для сброса фильтров и отображения всех предметов.
    Фильтрация по категориям
    Доступны категории: "Weapon" (оружие), "Armor" (броня), "Furnishings" (мебель), "Consumables" (расходуемые предметы), "Crafting" (ремесленные материалы).
    Каждая категория представлена кнопкой с иконкой и всплывающей подсказкой.
    При выборе категории отображаются только предметы, соответствующие этой категории.
    Возможность сбросить фильтр, повторно нажав на активную категорию.
    Поиск предметов
    Поле ввода для поиска предметов по названию.
    Поиск работает в реальном времени: при вводе текста список предметов автоматически фильтруется.
    Поддерживает поиск на любом языке (с учётом локализации игры).
    Управление предметами

    Выделение предметов: Левый клик по ячейке выделяет или снимает выделение с предмета (зелёная галочка). Заблокированные предметы нельзя выделить во время торговли.
    Контекстное меню: Правый клик по предмету открывает контекстное меню с действиями (например, "Экипировать", "Использовать"). Действие "Уничтожить" заблокировано для предотвращения случайного удаления.
    Экипировка и использование: Поддерживает экипировку оружия, брони и ювелирных изделий с учётом активной панели оружия (основная или запасная). Использование расходуемых предметов (например, зелий) через контекстное меню.
    Всплывающие подсказки: При наведении на предмет отображается его подробная информация (аналогично стандартному интерфейсу игры).

    Управление блокировкой предметов
    Кнопка Lock: Блокирует выделенные предметы (только оружие, броня, ювелирные изделия и предметы спутников).
    Кнопка Unlock: Снимает блокировку с выделенных предметов.
    Заблокированные предметы отображаются с затемнением (альфа 0.5) и не могут быть проданы во время торговли.
    Массовое выделение
    Кнопка Select All: Выделяет все предметы в текущем отображении (кроме заблокированных во время торговли).
    Повторное нажатие снимает выделение со всех предметов.
    Продажа предметов
    Кнопка Sell: Продаёт все выделенные предметы торговцу (до 50 предметов за раз).
    Работает только при открытом окне торговли (например, с NPC-торговцем).
    Заблокированные предметы не продаются.
    Отображение времени восстановления
    Для предметов с временем восстановления (например, зелий) отображается оверлей и таймер в секундах.
    Обновляется каждую секунду, если окно аддона открыто.
    Интерактивность и настройки
    Окно аддона можно перемещать по экрану.
    Поддерживает периодическое обновление содержимого (каждую секунду, если окно открыто).
    Автоматически сбрасывает выделение при закрытии окна.
    Клавиша для открытия/закрытия окна (название: "InventaryManagerTESO").
    Дополнительные функции
    Поддерживает работу с заблокированными предметами во время торговли (предотвращает их продажу).
    Автоматически обновляет содержимое при изменении инвентаря (например, после продажи или использования предмета).
    Совместимость с различными типами предметов, включая предметы спутников, кронные предметы и карты сокровищ.

Инструкция:

    Сетка предметов (слева): Отображает до 200 предметов в виде иконок (10×20).
    Панель управления (справа):
        Кнопка All: Показывает все предметы.
        Поле поиска: Для фильтрации предметов по названию.
        Кнопки категорий: "Weapon", "Armor", "Furnishings", "Consumables", "Crafting".
        Кнопки управления: Lock, Unlock, Select All, Sell.
        Информация: Внизу отображается "Занято/Всего слотов" (например, "125/200") и "Gold: <сумма>" (например, "1 860 657").
    Сортировка и фильтрация:
        Нажми All, чтобы отобразить все предметы.
        Нажми на категорию (например, "Weapon"), чтобы показать только предметы этой категории.
        Повторно нажми на активную категорию, чтобы сбросить фильтр.
        Введи текст в поле поиска, чтобы отфильтровать предметы по названию (работает в реальном времени).
    Управление предметами:
        Выделение: Кликни левой кнопкой мыши по предмету, чтобы выделить его (появится зелёная галочка). Повторный клик снимает выделение.
        Массовое выделение: Нажми Select All, чтобы выделить все предметы (кроме заблокированных во время торговли). Повторное нажатие снимает выделение.
        Блокировка/разблокировка: Выдели предметы, затем нажми Lock, чтобы заблокировать их (они затемнятся). Нажми Unlock, чтобы снять блокировку.
        Продажа: Открой окно торговли с NPC (например, торговцем). Выдели предметы и нажми Sell (продаётся до 50 предметов за раз). Заблокированные предметы не продаются.
        Экипировка/использование: Кликни правой кнопкой мыши по предмету, чтобы открыть контекстное меню. Выбери "Equip" (Экипировать) для оружия/брони или "Use" (Использовать) для расходуемых предметов.
        Просмотр информации: Наведи курсор на предмет, чтобы увидеть всплывающую подсказку с его описанием. Если у предмета есть время восстановления (например, зелье), отображается оверлей и таймер в секундах.
    Закрытие окна: Нажми "X" в правом верхнем углу или используй назначенную клавишу. Выделение предметов сбрасывается при закрытии.
    Полезные советы:
        Для быстрого поиска используй поле ввода.
        Во время торговли заблокированные предметы нельзя выделить или продать.
        Окно обновляется каждую секунду, если открыто.
