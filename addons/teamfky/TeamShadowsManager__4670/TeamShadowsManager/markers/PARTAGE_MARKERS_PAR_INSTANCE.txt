- Dans AddOns, il faut seulement les 4 dossiers :
  TeamShadowsManager
  LibTeamShadows
  TeamShadowsPing

NOTE POUR LES MEMBRES

Pour installer :
1. Fermer ESO ou faire l'installation avant /reloadui.
2. Dezipper TeamShadowsManager_COMPLETE.zip dans :
   Documents\Elder Scrolls Online\live\AddOns
3. Verifier que les 4 dossiers sont directement dans AddOns.
4. Relancer le jeu ou faire /reloadui.

Pour importer un pack :
1. Ouvrir Team Shadows Manager.
2. Onglet Import.
3. Choisir le raid a gauche.
4. Choisir Pack 1, Pack 2 ou Pack 3.
5. Coller le code partage dans la zone Import / Export.
6. Cliquer Importer, puis Rendre actif si besoin.
