# Baas Writ Crafter

Baas Writ Crafter is an addon for the Elder Scrolls Online (ESO).
Originally created by Dolgubon, maintained and customised by Baas.

The main purpose is to automate Crafting Writs, which are a daily quest in ESO.
A secondary purpose is to automate Master Writs, which are repeatable quests
requiring more advanced items to be crafted.

The addon fully supports all crafts for daily writs.

Other time saving features:
 - Automatically going through quest dialog
 - Automatic exiting of the crafting interface when crafting is complete
 - Automatic looting of the writ rewards
 - Bank withdraw for missing materials
 - Status bar showing writ progress
 - Master Writ tracking and crafting
 - Reset warnings before daily reset
 - Mail handler for writ reward containers
 - Stats window for tracking totals
and more!
