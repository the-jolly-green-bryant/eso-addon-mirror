Pawprints' PVP Tools Acknowledgements

The original idea for this addon was to replace Cyrodiil Mission Share which had been no longer updated.  Along the way I decided to wrap in a number of features and ideas from other addons.  While I referenced some of the underlying concepts (ie, ZOS functions, ZOS EVENTS, lua built-in functions like string.find()) I independently developed the code to implement those ideas.

Some of these elements are based around simple concepts (such as the map pins library) and as such are mentioned simply because I incorporated their idea into my own implementation.  In these cases, I did not even view their code and any duplication is purely coincidental.  I list them here because I got the basic idea for the feature from them.
