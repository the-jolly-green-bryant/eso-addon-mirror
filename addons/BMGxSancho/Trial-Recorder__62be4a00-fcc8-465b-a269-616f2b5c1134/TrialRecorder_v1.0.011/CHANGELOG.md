# Trial Recorder v1.0.011

- Fixed a PlayStation startup error in the Active Timer caused by unsupported label shadow methods.
- Preserved the live timer, positioning, scale, preview, clear tracking, vitality, and leaderboard behavior.

# Trial Recorder v1.0.010

- Added an optional live Active Timer that displays ESO's native raid duration.
- The timer updates once per second only while a scored raid is in progress.
- Added native console settings for enable/disable, horizontal position, vertical position, scale, and reset.
- Position and scale changes show a short preview so the timer can be placed without beginning a trial.
- Timer updates stop immediately when no raid timer is active.
- Existing clear tracking, vitality, leaderboard retrieval, menus, and stored records remain unchanged.
