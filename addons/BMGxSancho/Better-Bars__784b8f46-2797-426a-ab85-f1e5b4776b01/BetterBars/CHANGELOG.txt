Shield state correction (pre-release v0.0.01)
- Shield state now consumes ESO's authoritative add/update/remove event values directly.
- Invalid or stale shield visualizer values are rejected at the state owner.
- Shield capacity now uses ESO's reported shield maximum rather than a synthetic peak-current value.
- Health shield event acceptance now recognizes either Health attribute identity or Health power identity, improving Frost Staff / Wall shield compatibility.
- No renderer, texture, resource-bar, positioning, or smoothing behavior changed.
