Better Bars v0.0.02-dev2

A BMG Addon
Created and maintained by @BMGXSANCHO

Better Bars replaces ESO's native player resource bars with lightweight,
customizable Health, Magicka, Stamina, and Damage Shield displays.

Features
- Vertical Crescent and Horizontal layouts
- Independent Health, Magicka, Stamina, and Damage Shield controls
- Native ESO resource colors
- Numbers, Percentage, or Numbers & Percentage value display
- Per-bar position, scale, opacity, length, and thickness
- Five optimized Crescent depth profiles with left/right bow direction
- Automatic sizing from current maximum resources
- Damage Shield sizing from the current shield application's peak capacity
- Optional hiding of the Damage Shield bar when empty
- Character-specific settings
- Native player resource bars restored when Better Bars is disabled
- Optional native Chat HUD positioning, sizing, and scale controls
- HUD-scene visibility with settings preview support
- Event-driven resource updates with temporary smoothing only while values move

Dependency
- LibHarvensAddonSettings 2.0.007 or newer
