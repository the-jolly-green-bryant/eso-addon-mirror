Show CP v0.0.03

Displays the four currently slotted Champion Point stars for:
- Warfare (Blue)
- Fitness (Red)
- Craft (Green)

Each module can be enabled independently, scaled, and repositioned from Settings -> Addons -> Show CP.

Required library:
- LibHarvensAddonSettings

Show CP is local-only. It does not transmit any player information and does not maintain Champion Point presets.
