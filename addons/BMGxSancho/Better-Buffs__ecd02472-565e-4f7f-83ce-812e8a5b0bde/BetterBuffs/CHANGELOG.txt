Better Buffs v0.2.01 - Native Icon Mapping

- Added intentional ESO-native icon mappings for all 33 buffs and 29 debuffs in the built-in registry.
- Preserved live EVENT_EFFECT_CHANGED iconName as the highest-priority icon source.
- Corrected Pillager display artwork to use ability 172055 while retaining 172056 for recipient cooldown tracking.
- Added verified Touch of Z'en display ability 126597.
- Added verified native presentation mappings for Roar of Alkosh, Powerful Assault, Aura of Pride, normalized Major/Minor effects, Off Balance, Crusher, and status-effect previews.
- Built-in effects no longer depend on the consumable/potion fallback during Compact preview or before first observation.
- No changes to effect tracking, Combat Context, proc readiness, coverage, analytics, encounter lifecycle, layouts, settings, or SavedVariables.

Better Buffs v0.2.00 - Raid Effect Intelligence

- Preserves the v0.0.07 standalone Combat Context and one canonical Effect Runtime architecture.
- Adds canonical intelligence state for ACTIVE, COOLDOWN, READY, coverage, recipients, stacks, and target state.
- Adds Pillager recipient cooldown intelligence using verified combat-event ability ID 172056.
- Adds active-recipient presentation for Aura of Pride and observed multi-provider coverage capacity.
- Adds generic stack and release-trigger registry support without specialist trackers.
- Adds event-driven encounter analytics: uptime, applications, longest gap, average coverage, and lowest coverage.
- Adds Compact display style with Crescent, Grid, and Column layouts.
- Adds mirrored left/right crescent placement with configurable curve depth and vertical spread.
- Adds lightweight 12-segment perimeter timers, center countdowns, coverage badges, stack badges, dim cooldown state, and gold READY state.
- Adds priority-stable compact sorting plus alphabetical and time-remaining options.
- Adds 10-second UI-only preview data that never enters the canonical effect cache.
- Adds public Better Buffs API for effect state, target state, group coverage, encounter results, and callbacks.
- Keeps Buff and Debuff displays independently positioned and configured.
- No Conductor networking, Raid Sessions, Timeline, recommendation engine, or duplicate effect tracker was added.
