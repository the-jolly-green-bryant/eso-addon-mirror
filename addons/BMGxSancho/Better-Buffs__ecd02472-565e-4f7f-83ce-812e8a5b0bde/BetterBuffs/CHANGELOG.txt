Better Buffs v0.3.14

- Performance-only optimization pass; no new gameplay features or effect definitions.
- Reduced the single active-effect presentation update cadence from 100 ms to 200 ms while preserving immediate ESO event ingestion into the canonical cache.
- Compact Grid/Column/Crescent layouts now re-anchor tiles only when structural layout inputs change instead of on every timer tick.
- Compact perimeter ring anchors are recalculated only when tile size changes.
- Compact icon textures, desaturation, dimensions, and countdown fonts are now updated only when their underlying values change.
- Preserved one Effect Runtime, one canonical cache, event-driven Stats modules, Off Balance lifecycle, RO tracking, and all v0.3.13 functionality.

Better Buffs v0.3.13

- Preserved RO cooldown aura IDs 135924 / 137985 as native effect-change confirmation/fallback data.
- Weapon & Spell Damage now uses the same Better Buffs branded backdrop and gold border as the Current Pen / Crit module.
- Tank Resistance now uses the same Better Buffs branded backdrop and gold border as the Current Pen / Crit module.
- Added independent scale and opacity controls for Weapon & Spell Damage.
- Added independent scale and opacity controls for Tank Resistance.
- No new effect cache, tracker, polling loop, or event owner.

Better Buffs v0.3.12

- Restored the Better Buffs credits/header to the top of the main menu rather than its own settings section.
- Global Enable Better Buffs now immediately follows the credits block.
- Preserved v0.3.11 runtime ownership, SavedVariables migration, Compact/Detailed renderers, Stats Module, and scene-fragment behavior.

Better Buffs v0.3.11

- Added Feeding Frenzy tracking using ability ID 131353 for the Werewolf unique 6% damage buff.
- Added Sul-Xan's Torment testing support using community-supplied candidate ability ID 154737 for the 30-second collected-soul player buff.
- Added a dedicated Gear Sets settings category for gear-specific and Mythic effect tiles while preserving their existing runtime BUFF/DEBUFF behavior.
- Added the Analytics Stats Module with Self / Group (Future) / Hidden visibility.
- Stats Module displays Current Pen, Crit Chance, and Crit Damage from ESO-native stat APIs. During boss encounters Crit Damage also includes tracked target-side Major Brittle, Minor Brittle, and Elemental Catalyst stack modifiers.
- Current Pen adds only verified fixed resistance reductions that Better Buffs confirms are active on the current boss. Major Breach (5948) and Minor Breach (2974) are included.
- Variable-strength penetration effects such as Crusher and Roar of Alkosh are never guessed. When one is active, Current Pen is marked with an asterisk and held yellow until an authoritative magnitude can be derived.
- Stats colors: yellow below the useful target, green within +/-5% of the cap, red above the +/-5% window.
- Caps used by the module: 18,200 penetration, 100% critical chance, 125% critical damage.
- Stats Module is independently movable and supports scale and opacity controls.
- Group Stats remains explicitly future-facing and does not introduce networking in this build.
- Reworked the settings header into a proper Better Buffs section so credits have stable spacing at the top of the LibHarvens settings list.
- Preserved v0.3.10 Runtime-before-UI initialization and the single canonical Effect Runtime/cache architecture.
