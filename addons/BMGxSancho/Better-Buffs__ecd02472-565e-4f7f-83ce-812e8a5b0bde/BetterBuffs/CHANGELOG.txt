Better Buffs v0.3.06

Loadout-aware Warmask display release.

- Huntsman's Warmask now automatically becomes a tracked/displayed effect while item ID 223189 is equipped in the head slot.
- Removing Warmask immediately removes its automatic HUD relevance and clears its provider/Mark state through the existing equipment event path.
- The automatic state does not rewrite the character's saved checkbox. Manually enabled effects remain visible regardless of equipment; an otherwise-disabled Warmask tile appears only while the Mythic is actually equipped.
- Reused the existing EVENT_INVENTORY_SINGLE_SLOT_UPDATE subscription. No gear polling loop, secondary cache, or separate loadout tracker was added.
- Runtime, UI, preview, and timer update gates now consume the same manual-or-loadout relevance decision so the tile can appear/disappear immediately on gear swaps.

Better Buffs v0.3.05

Warmask ownership + group-coverage reconciliation release.

- Huntsman's Warmask now verifies the actual equipped mythic (item ID 223189) and consumes the verified local player effect 252050 as the authoritative owner/application state.
- Mark of Hircine 252048 is now target identity only. Another group member's Mark can no longer start your cooldown, drive your timer, or make your tile show READY.
- Warmask's 10-second application cooldown now starts from a genuine new local 252050 application, not from target-effect refreshes, eliminating the repeating 9-second cooldown loop.
- The local 252050 effect owns the 60-second Mark duration; 252048 supplies the marked target identity.
- Target death removes the target state while preserving only a still-valid local 10-second cooldown. Local 252050 fade clears the Mark for phase transitions/expiration.
- Equipment changes are handled by ESO's inventory-slot event. Unequipping Warmask immediately clears its local provider state without polling.
- Generic stale-FADE protection prevents an older group-buff application from deleting a newer recipient record that has already refreshed.
- Ferocious Roar combat events (ability IDs 39113/42155/42156/42157) trigger a one-shot Major Courage roster reconciliation after application. The reconciliation adds confirmed live Courage recipients without erasing still-valid recipients from another Courage source.
- Major Courage remains one normalized effect. No Werewolf-specific tracker, second cache, or periodic group scan was added.
- No additional EVENT_EFFECT_CHANGED or EVENT_COMBAT_EVENT owner was added.

Better Buffs v0.3.04

Lifecycle correctness audit release.

- Off Balance now uses the correct two-stage target lifecycle: active effect, then a 15-second target immunity cooldown only if that target survives the fade. Target death clears both immediately.
- Hostile debuff presentation now gives active bosses strict priority over previously cached trash targets. Existing trash state cannot take over a boss-fight tile.
- Reticle-target effects such as Mark of Hircine obey the same boss-priority rule during boss encounters.
- Encounter end now clears hostile target state without indiscriminately erasing real player/group buffs that are still active.
- Provider and recipient cooldown intelligence is preserved only according to registry ownership rules.
- Pillager READY is now affirmative: it does not glow READY until a real Pillager recipient event has established a provider in the current runtime.
- Elemental Catalyst is represented as one composite tile backed by Flame Weakness, Frost Weakness, and Shock Weakness child states. The stack badge represents active elemental weaknesses (0-3).
- Hostile target death clears target-owned cooldown state as well as active debuffs.
- No new tracker, cache, EVENT_COMBAT_EVENT owner, EVENT_EFFECT_CHANGED owner, or recurring update loop was added.
