# Maarselok HM Pad Markers

## Description
No more getting confused about which pad you need to run to for cleansing! 

This addon puts numbered icons on top of the pads for the Lair of Maarselok last boss fight. 

Note: Apperance of icons are not tied to enabling HM, they will be there even for Normal, and non-HM.

## Dependencies
OdySupportIcons
