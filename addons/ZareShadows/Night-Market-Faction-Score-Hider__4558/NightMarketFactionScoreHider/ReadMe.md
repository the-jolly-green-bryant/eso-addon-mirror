# Night Market Faction Score Hider

**AI assisted addon.**

Night Market Faction Score Hider hides the always-visible Night Market faction score and personal score elements.

## Version

1.0.1

## Features

- Hides the Advanced Zone HUD faction score display.
- Hides the related tracker container.
- Remembers whether the HUD is hidden or shown using ESO's `ZO_SavedVars` wrapper.
- Saves the setting account-wide and separates it by server using `GetWorldName()`.
- Adds a toggle keybind.
- Includes slash commands.
- Does not print addon-load chat spam.

## Recommended Keybind

Recommended: `F2`

After installing, go to:

Controls → Keybindings → General → Night Market Faction Score Hider

Then bind:

Toggle Faction Score HUD - Recommended: F2

## Slash Commands

```txt
/nmfsh
/nmfshhide
/nmfshshow
