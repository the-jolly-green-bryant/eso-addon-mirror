Instructions for use

"/esui"- toggles the eye strain on/off
"/ess"- opens the settigns menu

Keybinds are also available for the above options via the controls menu ingame.

The addon has the following options

The ability to select a colour, brightness level of that colour and opacity.
Recommend settings are a very dark red (almost black) with 30% opacity
