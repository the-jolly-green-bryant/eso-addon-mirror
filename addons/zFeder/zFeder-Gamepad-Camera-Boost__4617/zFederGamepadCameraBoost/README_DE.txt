zFeder Gamepad Camera Boost
==========================

Eigenes ESO-Addon fuer schnellere Gamepad-Kamera auf PC.

Ziel
----

Das Addon setzt nicht nur den alten globalen Gamepad-Camera-Slider, sondern nutzt die
neueren getrennten X/Y-Gamepad-Settings und die passenden ESO-CVars:

- GAMEPAD_SETTING_CAMERA_SENSITIVITY_X
- GAMEPAD_SETTING_CAMERA_SENSITIVITY_Y
- GamepadSensitivityFirstPersonX/Y
- GamepadSensitivityThirdPersonX/Y
- GamepadSensitivityFirstPerson.2
- GamepadSensitivityThirdPerson.2

Chat-Befehle
------------

/zfgamepad status
/zfgamepad set 5
/zfgamepad set 5 4
/zfgamepad apply
/zfgamepad on
/zfgamepad off

Empfohlener Start
-----------------

Die Voreinstellung ist bereits:

/zfgamepad set 2.15

Wenn das noch zu langsam ist:

/zfgamepad set 5

Extreme Tests:

/zfgamepad set 8
/zfgamepad set 10

Nicht gleichzeitig nutzen
-------------------------

Zum Testen sollten andere Gamepad-Kamera-Tuner deaktiviert werden, sonst koennen AddOns
sich gegenseitig ueberschreiben:

- IsJusta Gamepad Camera Accelerator
- Zoruah's Gamepad Tuner
