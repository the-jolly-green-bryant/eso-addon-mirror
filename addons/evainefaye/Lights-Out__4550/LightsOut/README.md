# Lights Out (ESO Add-On)

Lights Out turns interactable furnishings in an ESO house into competitive mini games.

Compete solo or with others by battling over the state of objects in your home—flip lights, rotate states, and outplay your opponents in real time.

---

## 🎮 Game Modes

### Threshold
Each team is assigned an item and a winning state.  
Teams race to get a required number of their items into that state.

### Target
A subset of items is randomly selected as scoring targets.  
- Targets always start in the non-winning state  
- Remaining items are randomized  
- No feedback is given when you score  

First to reach the goal—or closest when time expires—wins.

### War
All teams share a single item type.  
- Each team is assigned a unique state  
- Number of teams = number of available states  
- Items must remain in a state for **5 seconds** before counting  

---

## ⚡ Quick Start

1. Open the Control Panel:
   /lo
   or
   /lightsout

2. Click **Populate** to scan your house for usable items

3. Configure your game:
   - Select mode
   - Set required targets
   - Set time limit (optional)
   - Enable teams

4. Click **Start** to begin

---

## 🛠 Managing Teams

### Rename a Team
- Left-click the team name  
- Press **Enter** to save or **Esc** to cancel  
- Names must be unique within their group  

### Change Winning State
- Click the state field  
- Select a new state from the popup  

---

## 🔘 Enabling Teams

- Use toggle switches to enable teams  

### Rules:
- **Target / Threshold:**  
  Teams must have the same item count  
- **War:**  
  All teams must use the same item type  

---

## ➕ Adding Items

### Automatic
Use **Populate** to scan and add items

### Manual
If an item is missed:
1. Open housing editor
2. Select the item
3. Run:
   /lo add <teamname>
   or
   /lo add war <teamname>

---

## ▶️ Starting a Game

Once configured, click **Start**.

- Items are reset to their starting states
- Game status window appears showing:
  - Team names
  - Items/states
  - Progress counts
  - Percent completion

---

## 🔄 Dynamic Item Tracking

- Added items are detected automatically  
- Removed items update counts  
- Active game changes cancel the game
