Lvx Journal - Chronicles

Install:
Copy the LvxJournal folder into:
Documents/Elder Scrolls Online/live/AddOns/

Optional support:
- LibMapPins: used for map pin rendering when installed.
- LvxJournal also includes an internal fallback pin renderer for testing/independent use.
- Clock: optional RP time support.
- LvxJournal_PersonalNotesBackup: optional backup module.

No executables are included.
