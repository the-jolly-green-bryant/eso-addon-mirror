# WeaveDelays

## Colorblind accessibility

The delay bar's color palette can be changed in the settings menu.
The `okabeito` palette uses the Okabe-Ito color set, designed to remain distinguishable for the most common types of color blindness.
Alternative options which might also work well are `cividis` and `viridis`.

Test the colorscheme with the slash command:

````
/wdcolortest
````

Colors shown on the left side are good (low) delays right side are bad (too long) delays, increasing linearly from -50 up to 450 ms.
