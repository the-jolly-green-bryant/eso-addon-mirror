# FadePins
![PREVIEW](PREVIEW.png)

An addon for The Elder Scrolls Online that fades out other pin groups on mouseover when the game's map is open. It should be compatible with other addons which add or alter map pins, but if you encounter issues, please report it [under the "Issues" tab](https://github.com/JGeurrie/FadePins/issues).

**No other addons are required to use FadePins; it has no dependencies.** You can change the opacity of faded pins by opening `FadePins.lua` and changing `local FADE_MODIFIER = 0.25` to anything you wish... though, it should *probably* be a number between `0.0` and `1.0`.

**This version of FadePins is up-to-date with API version 101049 (March 30th, 2026).** That said, FadePins only reads and alters the opacity of pins you hover over while the map is open; all you'll experience if it's out-of-date *and* broken are error pop-ups and graphical bugs.
