# Tetsu's Combat Healer Helper 1.4.0

Console (PS5 / Xbox) healer HUD for The Elder Scrolls Online.

## What it does

HUD grid, up to 5 columns. Filled green dot = that player currently has the selected buff or heal.

Head icons and ground puddles are not in this build. Tracking first, world markers later from scratch.

## Requirements

- LibHarvensAddonSettings
- API 101050 / 101051
