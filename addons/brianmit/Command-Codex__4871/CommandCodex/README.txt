Command Codex 1.0.0 - by brianmit
=================================

Every slash command from the game and your addons in one window,
grouped by addon.

OPEN IT
  Click the "Command Codex" button (top left), or type /codex

IN THE WINDOW
  Arrow  ...........  run the command
  Star  ............  add to favorites
  Double-click  ....  put it in chat
  Right-click  .....  more (bind a key, add a note, ...)

FAVORITES ON SCREEN
  Each favorite becomes a small button you can drag anywhere.
  Padlock in the window: lock / unlock them.
  Right-click a favorite > Bind a Key... to run it with a key.

SETTINGS
  Settings > Addons > Command Codex
  Language and favorite sets (per character, PvP or house).
  This page uses LibAddonMenu-2.0 (the rest works without it).

CHAT COMMANDS
  /codex help   shows all commands in chat
