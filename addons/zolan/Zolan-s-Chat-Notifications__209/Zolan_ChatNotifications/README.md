Zolan_ChatNotifications
=======================

ESO Addon that alerts you when a chat message you care about comes in.

You can find the settings in SETTINGS->Zolan's Addons.

Pretty straight forward stuff.

This is my first addon so feel free to send me some
constructive criticism.
