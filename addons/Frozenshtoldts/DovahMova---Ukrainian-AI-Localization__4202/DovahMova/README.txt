========================================
DovahMova - Український переклад для ESO
========================================

ОПИС
-----
DovahMova - це аддон для The Elder Scrolls Online, який додає український переклад 
інтерфейсу гри. Аддон автоматично перекладає назви предметів, здібностей, 
колекцій та інших елементів гри на українську мову.

ВЕРСІЯ: 1.4.0
АВТОР: Frozenshtoldts та DovahMova Team

НАЛАШТУВАННЯ
------------
1. Встановіть аддон у папку AddOns
2. Запустіть ESO
3. Перейдіть у налаштування аддонів
4. Знайдіть DovahMova та налаштуйте параметри:

   - Мова інтерфейсу: Виберіть "Українська"
   - Режим відображення назв предметів:
     * "ua" - тільки українські назви
     * "uaen" - українські назви з англійськими дужками
   - Автоматичне оновлення перекладів: Увімкнено/Вимкнено

КОМАНДИ
-------
/dovamova - Відкрити налаштування аддону
/dovamova help - Показати довідку
/dovamova update - Оновити базу перекладів
/testmail - Перевірка налаштувань автозбору листів
/collectmail - Примусовий запуск збору листів

========================================
АВТОЗБІР ЛИСТІВ НАЙМАНЦІВ
========================================

DovahMova включає вбудований функціонал автоматичного збору матеріалів 
з листів від найманців при відкритті поштової скриньки.

ОСОБЛИВОСТІ:
✓ Автоматичний збір матеріалів з листів найманців
✓ Опціональне видалення листів після збору
✓ Підтримка українських та англійських назв листів
✓ Оптимізована обробка з затримкою 300мс між листами

НАЛАШТУВАННЯ:
В меню налаштувань DovahMova (ESC -> Налаштування -> Аддони -> DovahMova) 
в розділі "Загальні":
- "Автозбір листів від найманців" - вмикає/вимикає автоматичний збір
- "Видаляти листи після збору" - автоматично видаляє листи після збору

ПІДТРИМУВАНІ ЛИСТИ:

- Матеріали від коваля
- Матеріали від кравця

- Матеріали від зачарувальника
- Інгредієнти від постачальника
- Матеріали від ювеліра

TAMRIEL TRADE CENTRE (TTC) ІНТЕГРАЦІЯ
------------------------------------

DovahMova підтримує інтеграцію з Tamriel Trade Centre для відображення 
цін предметів у українських назвах.

ШВИДКИЙ СТАРТ (Windows):
1. Переконайтеся, що у вас встановлений Tamriel Trade Centre
2. Запустіть скрипт інтеграції:
   - Знайдіть файл: addon\DovahMova\integration\TamrielTradeCentreUA\ttc_ua_setup.bat
   - Запустіть скрипт
3. Перезапустіть ESO
4. Переконайтеся, що мова клієнта ESO встановлена на українську
5. Відкрийте налаштування DovahMova (Налаштування -> Доповнення -> DovahMova)
6. У розділі "Загальне" натисніть кнопку "Згенерувати таблицю для TTC"
7. Дочекайтеся завершення генерації таблиці

ШВИДКИЙ СТАРТ (macOS):
1. Переконайтеся, що у вас встановлений Tamriel Trade Centre
2. Запустіть скрипт інтеграції:
   - Відкрийте Terminal (Програми -> Утиліти -> Термінал)
   - Перейдіть до папки з аддонами: cd ~/Documents/Elder\ Scrolls\ Online/live/AddOns/
   - Перейдіть до папки скрипта: cd DovahMova/integration/TamrielTradeCentreUA/
   - Надайте дозволи на виконання: chmod +x ttc_ua_setup.sh
   - Запустіть скрипт: ./ttc_ua_setup.sh
3. Перезапустіть ESO
4. Переконайтеся, що мова клієнта ESO встановлена на українську
5. Відкрийте налаштування DovahMova (Налаштування -> Доповнення -> DovahMova)
6. У розділі "Загальне" натисніть кнопку "Згенерувати таблицю для TTC"
7. Дочекайтеся завершення генерації таблиці

ДЕТАЛЬНА ІНСТРУКЦІЯ (Windows):
1. Закрийте ESO
2. Відкрийте папку з аддонами:
   C:\Users\[ваше_ім'я]\Documents\Elder Scrolls Online\live\AddOns\
3. Перейдіть в папку DovahMova\integration\TamrielTradeCentreUA\
4. Запустіть скрипт ttc_ua_setup.bat
5. Дочекайтеся завершення встановлення
6. Запустіть ESO
7. Відкрийте налаштування DovahMova (Налаштування -> Доповнення -> DovahMova)
8. У розділі "Загальне" натисніть кнопку "Згенерувати таблицю для TTC"
9. Дочекайтеся завершення генерації таблиці
10. Перевірте статус командою /debugttcua (опціонально)

ДЕТАЛЬНА ІНСТРУКЦІЯ (macOS):
1. Закрийте ESO
2. Відкрийте Terminal (Програми -> Утиліти -> Термінал)
3. Перейдіть до папки з аддонами:
   cd ~/Documents/Elder\ Scrolls\ Online/live/AddOns/
4. Перейдіть в папку скрипта:
   cd DovahMova/integration/TamrielTradeCentreUA/
5. Надайте дозволи на виконання скрипта:
   chmod +x ttc_ua_setup.sh
6. Запустіть скрипт:
   ./ttc_ua_setup.sh
7. Дочекайтеся завершення встановлення (натисніть Enter коли скрипт завершиться)
8. Запустіть ESO
9. Відкрийте налаштування DovahMova (Налаштування -> Доповнення -> DovahMova)
10. У розділі "Загальне" натисніть кнопку "Згенерувати таблицю для TTC"
11. Дочекайтеся завершення генерації таблиці
12. Перевірте статус командою /debugttcua (опціонально)

РУЧНЕ ОНОВЛЕННЯ:
Система зберігає згенеровану таблицю між сесіями гри. Оновлення потрібно виконувати вручну:
- При оновленні DovahMova або додаванні нових перекладів
- При зміні налаштувань відображення (ua/uaen)
- Використовуйте кнопку "Згенерувати таблицю для TTC" в налаштуваннях DovahMova

КОМАНДИ TTC ІНТЕГРАЦІЇ:
/generateua - Вручну створити українські мапінги (з детальним виводом)
/debugttcua - Перевірити статус інтеграції
/debugua [назва_предмета] - Відлагодити пошук конкретного предмета

ВИРІШЕННЯ ПРОБЛЕМ:
- Якщо з'являється помилка "unsupported language":
  * Переконайтеся, що мова ESO встановлена на українську
  * Перевірте, чи правильно запустився скрипт інтеграції
  * Спробуйте перезапустити ESO

- Якщо ціни не відображаються:
  * Система автоматично оновлює мапінги при змінах
  * Для ручного оновлення використайте команду /generateua
  * Перевірте статус командою /debugttcua
  * Переконайтеся, що TTC база даних оновлена

- Проблеми специфічні для macOS:
  * Якщо скрипт не запускається: переконайтеся, що ви надали дозволи (chmod +x ttc_ua_setup.sh)
  * Якщо папка AddOns не знайдена: перевірте шлях ~/Documents/Elder\ Scrolls\ Online/live/AddOns/
  * При помилці "Permission denied": запустіть chmod +x ttc_ua_setup.sh ще раз
  * Якщо Terminal не знаходить файл: переконайтеся, що ви в правильній папці (pwd для перевірки)
  * Для відлагодження використайте: ls -la щоб побачити файли та їх дозволи

COMBATMETRICS ІНТЕГРАЦІЯ
------------------------

DovahMova включає повну українську локалізацію для популярного аддону 
CombatMetrics, який аналізує бойову ефективність гравця.

ОСОБЛИВОСТІ ІНТЕГРАЦІЇ:
✓ Повний український переклад всіх елементів інтерфейсу CombatMetrics
✓ Переклад бойових термінів (урон, лікування, УВС, ЛВС)
✓ Українські назви ресурсів (здоров'я, магія, витривалість, ультимейт)
✓ Локалізація статистики та звітів
✓ Переклад меню та налаштувань

ШВИДКИЙ СТАРТ:
1. Переконайтеся, що у вас встановлений CombatMetrics
2. Встановіть DovahMova (інтеграція включена автоматично)
3. Переконайтеся, що мова ESO встановлена на українську
4. Перезапустіть ESO
5. Відкрийте CombatMetrics - всі елементи будуть українською мовою

ПЕРЕКЛАДЕНІ ЕЛЕМЕНТИ:
• Основні бойові терміни (урон, лікування, блоки, криты)
• Статистика (УВС - урон в секунду, ЛВС - лікування в секунду)
• Ресурси (здоров'я, магія, витривалість, ультимейт)
• Звіти та аналіз бою
• Меню та налаштування
• Повідомлення та підказки

КОМАНДИ COMBATMETRICS:
/combatmetricstest - Запустити тест інтеграції CombatMetrics
/cmtest - Короткий тест інтеграції
/testtranslations - Перевірка перекладів
/cmintegrationdebug - Детальна діагностика інтеграції
/cmforceregister - Примусова реєстрація інтеграції

ВИРІШЕННЯ ПРОБЛЕМ COMBATMETRICS:
- Якщо переклади не з'являються:
  * Переконайтеся, що мова ESO встановлена на українську
  * Перезапустіть ESO командою /reloadui
  * Запустіть тест командою /combatmetricstest
  * Використайте /cmintegrationdebug для діагностики
  * Спробуйте /cmforceregister для примусової реєстрації

- Якщо інтеграція не реєструється:
  * Запустіть /cmintegrationdebug щоб побачити статус
  * Переконайтеся, що обидва аддони завантажені
  * Спробуйте /cmforceregister для ручної реєстрації
  * Перезапустіть ESO якщо проблема не зникає

- Якщо переклад з'являється із затримкою:
  * Це нормально - іноді локалізація застосовується через кілька секунд
  * Спробуйте закрити та знову відкрити вікно CombatMetrics

DovahMova включає повну українську локалізацію для популярного аддону 
PotionMaker, який допомагає створювати зілля та отрути.

ОСОБЛИВОСТІ ІНТЕГРАЦІЇ:
✓ Повний український переклад всіх налаштувань PotionMaker
✓ Переклад назв ефектів зілль (відновлення здоров'я, магії, витривалості тощо)
✓ Українські назви позитивних та негативних ефектів
✓ Локалізація інтерфейсу пошуку та фільтрів
✓ Переклад системи обраного
✓ Локалізація всіх повідомлень та підказок

ШВИДКИЙ СТАРТ:
1. Переконайтеся, що у вас встановлений PotionMaker
2. Встановіть DovahMova (інтеграція включена автоматично)
3. Переконайтеся, що мова ESO встановлена на українську
4. Перезапустіть ESO
5. Відкрийте PotionMaker - всі опції будуть українською мовою

ПЕРЕКЛАДЕНІ ЕЛЕМЕНТИ:
• Основні налаштування пошуку та фільтрації
• Налаштування відображення результатів
• Система обраного (favorites)
• Опції використання невідомих ефектів
• Налаштування для тренування навичок
• Інтеграція з ItemSaver
• Всі назви ефектів та властивостей реагентів

ЕФЕКТИ ЗІЛЛЬ:
• Відновлення ресурсів - здоров'я, магія, витривалість
• Спустошення ресурсів - негативні ефекти
• Бойові ефекти - сила зброї, сила заклинань, критичний рейтинг
• Захисні ефекти - броня, опір заклинанням
• Спеціальні ефекти - швидкість, невидимість, непереможність
• Тривалі ефекти - тривале здоров'я, життєвість, захист

КОМАНДИ POTIONMAKER:
/potionmakertest - Запустити тест інтеграції PotionMaker
/pmtest - Короткий тест інтеграції
/pottesttrans - Перевірка перекладів
/pottestui - Перевірка інтерфейсу
/potfulltest - Повний тест всіх компонентів

ВИРІШЕННЯ ПРОБЛЕМ POTIONMAKER:
- Якщо налаштування не перекладені:
  * Переконайтеся, що мова ESO встановлена на українську
  * Перезапустіть ESO командою /reloadui
  * Запустіть тест командою /potionmakertest
  * Перевірте, що PotionMaker встановлений та активний

- Якщо переклад з'являється із затримкою:
  * Це нормально - іноді локалізація застосовується через кілька секунд
  * Спробуйте закрити та знову відкрити вікно PotionMaker

- Якщо інтеграція не працює:
  * Використайте /potfulltest для діагностики
  * Переконайтеся, що обидва аддони завантажені
  * Перевірте версію PotionMaker (підтримується 5.10.2+)
