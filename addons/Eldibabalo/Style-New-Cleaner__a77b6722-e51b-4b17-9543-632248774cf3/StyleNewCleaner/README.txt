Style New Cleaner - Overview
============================

Purpose
- Clears all "NEW" markers in Outfit Styles (armor + weapon) in one action.
- Saves time compared to opening each style entry one by one.

How to use
- Slash command: /snc
- Alternate command: /clearstylesnew
- At Outfit/Restyle station (gamepad): press R3 ("Clear New Styles")

What it clears
- New status for collectible entries in the Outfit Styles category.
- This targets style notifications, not unrelated collection categories.
- Also removes matching style collectible notifications when available.

Notes
- Works best while UI is fully loaded (after login/reload).
- If your client blocks a keybind in station UI, use /snc instead.
