[B]ESO ADVENTURER SUITE[/B]
Author: HoZayyBadazz
Version: 0.29.197
Status: Public Beta

ESO Adventurer Suite is an all-in-one Elder Scrolls Online dashboard and utility addon built around the Tamriel Codex. It combines questing, travel, exploration, combat guidance and statistics, action-bar/HUD customization, minimap tools, build optimization, companion utilities, activity tracking, treasure hunting, antiquities assistance, notes, checkpoints, Golden Pursuits integration, and configurable gameplay overlays in one Suite.

[B]REQUIRED LIBRARIES[/B]
Install and enable these separately through Minion/ESOUI:

* LibAddonMenu-2.0 >= 43
* LibMapData >= 101
* LibGPS >= 73
* LibMapPins-1.0 >= 47
* LibMapPing
* LibDebugLogger
* LibChatMessage
* LibTreasure >= 24 
* CustomCompassPins >= 138


[B]NEW / HIGHLIGHTED IN 0.29.197[/B]
* New Keep desktop UI while using controller option keeps the normal PC/keyboard-style in-game UI while ESO Gamepad Mode remains On/Automatic for controller input
* Controller-aware Suite overlays still show the actual controller bindings/glyphs while desktop UI lock is active
* Smart Combat Advisor now prefers action-bar highlighting during normal combat instead of the large recommendation card

* LibMapPing, LibDebugLogger, and LibChatMessage are declared required with the LibGPS support stack
* Map Teleporter remains mouse/keyboard operated

[B]INSTALL / UPDATE[/B]
1. Install the required libraries listed above.
2. When updating manually, remove the old ESOAdventurerSuite folder first so deleted/renamed files cannot remain behind.
3. Extract the ZIP so the path is: Documents/Elder Scrolls Online/live/AddOns/ESOAdventurerSuite/ESOAdventurerSuite.txt
4. Enable ESO Adventurer Suite and its required libraries at the character-select Add-Ons screen.
5. Log in and use Settings > Addons > ESO Adventurer Suite.

[B]CONTROLLER NOTE[/B]
Keep desktop UI while using controller can prevent ESO from replacing the logged-in PC interface with its console-style Gamepad UI while retaining controller input. Controller glyph support remains binding-aware. Force PlayStation applies after addons load, so pre-login/character-select UI and glyphs are outside addon control. The Suite Map Teleporter is intentionally mouse/keyboard operated.
