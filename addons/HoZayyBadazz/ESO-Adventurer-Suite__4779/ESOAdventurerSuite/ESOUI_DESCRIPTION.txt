[B]# ESO ADVENTURER SUITE[/B]
Author: HoZayyBadazz
Version: 0.27.78
Status: Public Beta

ESO Adventurer Suite is an all-in-one Elder Scrolls Online gameplay and progression utility built around the Tamriel Codex and configurable HUD overlays. It includes quest and travel tools, Dungeon Finder utilities, gear/set tools, live equipment display, role-aware progression guidance, combat statistics, custom unit frames, minimap features, Golden Pursuits integration, and Active Quest tracking.



[B]# CUSTOM ESO RETICLE[/B]
- Optional Suite-owned ESO-style reticles with ESO Default available at any time.
- Styles include Tamriel Rune, Corner Brackets, Compass Cross, Minimal Cross, Daedric Diamond, Ayleid Star, and Dragon Eye.
- Reticle controls are available in Tamriel Codex > Utilities and in Settings > Addons > ESO Adventurer Suite.
- Size and opacity include both decrease and increase controls.
- Color choices include ESO Gold, Ivory, Crimson, Arcane Blue, and RGB Rainbow cycling.
- Custom reticles replace only the center crosshair graphic; ESO interaction prompts and target text remain intact.

[B]# CURRENT TRAVEL & HISTORY FEATURES[/B]
- Quest travel resolves the selected/current objective to a discovered wayshrine in the proper destination zone, with Main Story/Harborage alliance handling where ESO reports an instance instead of an overland zone.
- Direct travel tools include nearest merchant, nearest guild store/trader, and guild-leader primary residence (with a guild selector when the player belongs to multiple guilds). All travel requires an explicit player click and remains subject to ESO travel/access restrictions.
- Dungeon History records future dungeon completions, mode when ESO exposes it, character, date/time, and duration; older achievement timestamps are imported only where ESO exposes reliable historical evidence.
- Activity History covers supported Trials, Arenas, Battlegrounds, PvP sessions, and Archive-style activities with paged history.
- Group Finder social tools use ESO public listings and guild rosters only. The public build does not collect or retain an arbitrary nearby/non-grouped-player roster.

[B]# QUEST TRACKING[/B]
Settings > Quest Tracking lets you choose exactly one tracking source:
- Active Quest: follows the selected non-main Quest Finder / ESO journal quest.
- Golden Pursuits: follows the journal quest linked to the selected Golden Pursuit.
- Main Quest: follows an accepted Main Story quest only.

Only the chosen source drives the visible Suite quest tracker and ESO assisted quest/compass at a time. Active Quest, Golden Pursuits, and Main Quest are kept independent so one source does not overwrite another. The Suite uses ESO's native compass guidance for the selected quest; the custom direction-arrow HUD has been removed.

[B]# DEPENDENCIES[/B]
Required dependencies:
- LibAddonMenu-2.0 r43 or newer
- LibMapData (AddOnVersion 101+)
- LibGPS 3.x (AddOnVersion 30+)
- LibMapPins-1.0 r47 or newer

Install the libraries separately with Minion/ESOUI. LibGPS also uses its own declared library dependencies.

ESO Adventurer Suite will not load if any required dependency is missing or older than the minimum version declared in the manifest.

[B]# ESOUI REVIEW / PERFORMANCE NOTES[/B]
- Required LibAddonMenu-2.0 uses DependsOn with the current minimum AddOnVersion check (>=43).
- Account-wide SavedVariables are namespaced by GetWorldName() so NA, EU, and PTS data do not overwrite one another.
- EVENT_COMBAT_EVENT analytics use EVENT_MANAGER:AddFilterForEvent combat-result/source/target filters rather than broad Lua-side result classification.
- The manifest declares only two supported API versions: 101050 101051.
- No executables, DLLs, telemetry upload, external network access, or arbitrary local file access are included.
- No non-grouped nearby-player detection roster, map-ping data sharing, combat/movement automation, automatic chat sending, external-service communication, or Suite-controlled nameplate modification is included.
