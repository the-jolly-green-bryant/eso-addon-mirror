DISPLAY LEADS REFERENCE DATA
AntiquityLeadData.lua incorporates lead source/location reference information
from the user-supplied Display Leads addon by remosito (Display Leads 42.0).
The Suite uses ESO's live API for current lead ownership/progress and uses the
integrated reference table only for acquisition/source descriptions and
find-zone overrides. Original authorship of that reference information remains
with its source project/contributors.

LIBTREASURE INTEGRATION
The Suite Treasure & Survey Locator uses the public runtime API/data provided by
LibTreasure when that optional library is installed. LibTreasure remains a
separate third-party library and is not redistributed as Suite-owned code.
The user-supplied LostTreasure addon was used as a behavior/reference example;
the Suite locator implementation is Suite-native and LostTreasure itself is not
required.

GAMEPAD GLYPH REDIRECTION REFERENCE
The Suite-wide XInput-to-PlayStation glyph redirection behavior was implemented
with reference to the open-source "Custom gamepad button glyphs" project by
13xforever (teso-gamepad-glyphs), which demonstrates RedirectTexture-based
remapping of ESO's built-in controller art. That project is MIT-licensed.



ACTION BAR BEHAVIOR / SKILL STYLE REFERENCES

and the publicly documented Action Bar Skill Styles / Fancy Action Bar+ behavior.
No Fancy Action Bar+ or Action Bar Skill Styles files, artwork, or bundled runtime
