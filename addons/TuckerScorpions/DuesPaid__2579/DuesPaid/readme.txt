# DuesPaid

;DuesPaid is an addon for the Elder Scrolls Online(ESO).
;The main purpose is to remind a player to pay their guild dues.
;Unzip the DuesPaid.zip folder to you addon's folder.
;You will need two library files for the DuesPaid addon to work.
;They are LibNotification,and LibAddonMenu-2.0
