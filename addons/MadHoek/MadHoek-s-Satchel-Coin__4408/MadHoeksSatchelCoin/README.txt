MadHoek’s Satchel & Coin (MHSBC)
Version: 3.0.8
Author: MadHoek

Description
-----------
Displays Bag, Bank, Gold, and optional currency information in a customizable on-screen element.

Features
--------
Primary Row:
- Bag space
- Bank space (including subscriber bank)
- Gold

Currency Row (optional):
- Bank Gold
- Tel Var Stones
- Alliance Points
- Writ Vouchers
- Trade Bars

Layout Behavior:
- Gold icon click toggles the currency row.
- If the entire primary row is disabled, the currency row will be shown.
- One-per-session message appears if all displays are disabled.

Customization Options
---------------------
Available in the in-game Addon Settings menu:

- Show / hide the entire HUD window
- Lock / unlock window position
- Window transparency
- Font size (scales text, icons, and spacing proportionally)
- Warning thresholds (Bag / Bank)
- Show / hide individual elements
- Enable / disable currency row
- Customizable text colors (Normal / Warning / Full)
- Reset colors to default

Keybinds & Commands
-------------------
Keybinds (configurable in Controls → Addons):
- Toggle MHSBC window
- Toggle window lock

Slash Commands:
- /mhsbcv   Toggle window visibility
- /mhsbcm   Toggle window lock/movable

Installation
------------
Extract the folder to:
Documents\Elder Scrolls Online\live\AddOns\

Ensure LibAddonMenu-2.0 is installed.

Compatibility
-------------
Updated for API version 101049.
