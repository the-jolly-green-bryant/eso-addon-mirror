# MadHoek's Companion Wardrobe

Companion Wardrobe is a complete companion loadout and build management addon for **The Elder Scrolls Online**.

## Inspired by Wizard's Wardrobe

Companion Wardrobe was inspired by the excellent Wizard's Wardrobe addon and applies a similar loadout-management philosophy to ESO companions.

Wizard's Wardrobe:
https://www.esoui.com/downloads/info3170-WizardsWardrobe.html

Rather than managing player builds, Companion Wardrobe focuses entirely on companion equipment, companion skills, companion progression, and companion-specific quality-of-life features.

## Philosophy

> Companion management should be fast, predictable, and transparent.

Save, load, inspect, organize, share, and manage companion builds with support for companion gear, skills, validation systems, warning indicators, import/export functionality, and bank-assisted gear management.

No more manually rebuilding companion setups every time you switch roles, activities, or companions.

# Validation & Warning System

Companion Wardrobe continuously validates saved loadouts and helps identify problems before they become confusing.

The addon can detect:

* Missing gear
* Locked skill slots
* Locked skill lines
* Invalid saved skills
* Companion progression conflicts

Warnings are displayed through:

* Visual warning indicators
* Text warning indicators
* Detailed warning tooltips

This helps explain exactly why a loadout cannot be applied as originally saved.

---

# Gear Management

Companion Wardrobe includes several tools designed to reduce repetitive inventory management.

Features include:

* Missing gear detection
* Equipped gear detection
* Backpack scanning
* Bank integration
* Automatic gear fetch queues
* Automatic gear storage queues
* Two-handed weapon handling

Missing gear can be automatically retrieved from the bank, while unused loadout gear can be stored with a few clicks.
