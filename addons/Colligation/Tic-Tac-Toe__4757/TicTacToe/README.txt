# Queue Time Tic-Tac-Toe

A simple Tic-Tac-Toe minigame for Elder Scrolls Online.

Play against an AI while waiting in dungeon, battleground, or activity finder queues.

## Features

- Single player Tic-Tac-Toe
- Easy / Normal / Hard AI
- Movable window
- Resizable UI
- UI scaling
- Multiple themes
- Win/Loss tracking
- LibAddonMenu settings

## Commands

/ttt
- Toggle window

/tttshow
- Show window

/ttthide
- Hide window

/tttdifficulty easy|normal|hard
- Change AI difficulty

/tttmove
- Toggle window movement

/tttscale 0.5-2
- Change UI scale

/tttresetstats
- Reset statistics

## Dependencies

LibAddonMenu-2.0
