Petrify Timer
==============

A PvP-focused ESO addon designed to help players react quickly to
crowd control abilities with visual alerts, dodge timing, and combat tracking.

Originally created for Dragonknight Petrify, Fossilize, and Shattering Rocks,
the addon has expanded into a multi-CC awareness tool.


Features
--------

- Petrify detection
- Fossilize detection
- Shattering Rocks detection
- Multi-CC support system
- Crowd Control immunity detection
- "ROLL NOW FN" warning alert
- Dodge timing countdown
- Animated CC icon
- Flashing red warning border
- Movable UI
- Saved UI position
- Adjustable UI scale
- Edit mode
- Lockable UI
- Combat statistics tracking


Statistics
----------

Tracks player CC encounters:

- Total CC hits detected
- Persistent statistics


Commands
--------

/petrifytest

Test the alert, animation, and timer.


/petrifyedit

Show the UI and allow movement.


/petrifyscale #

Change UI size.

Example:
 /petrifyscale 1.5


/petrifylock

Lock the UI position.


/petrifyunlock

Unlock the UI position.


/petrifyreset

Reset UI position and scale.


/petrifystats

Display combat statistics.


/petrifyhelp

Show all available commands.
