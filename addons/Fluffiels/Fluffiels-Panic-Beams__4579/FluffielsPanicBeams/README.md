Fluffiels' Panic Beams
==================

This is an Addon which will help you find low HP or dead group members so you can res there as fast as possible so they can get back to the fight.
It also shows a beam on the group leader, so it's easier to follow them.


If a group member dies, an arrow will point in the direction of the closest one.
If a group member dies, a red beam will appear at their location. If the group member is being revived, the beam turns yellow. If pending rez, green.
Shows a blue beam on the group leader.
Shows orange beams on group members with low HP.


There are several options of arrow layouts and options to change the opacity and size of the arrow(s). 

This addon is a fork of the [Merlin's Rez Helper](https://www.esoui.com/downloads/info1600-MerlinsRezHelper.html)
Which is a fork of the "Exterminatus Group Leader" [V1](http://www.esoui.com/downloads/info329-ExterminatusGroupLeader.html) [V2](http://www.esoui.com/downloads/info922-ExterminatusGroupLeader.html)
Added ideas from "I See Dead People", and "Follow the Crown" sub-addons of the [RdK Group Tool](https://www.esoui.com/downloads/info2475-RdKGroupTool.html)



Features:


**Revive Assistance**
 * Shows an arrow pointing in the direction of the closest dead group member
 * The arrow disappears if the group member is being, or pending rez
 * Several sound alerts to choose from, to get notified when someone dies

**I See Dead People**
 * Shows a red beam at the location of a dead group member
 * The beam changes to yellow when the dead player is being revived. And then green when pending rez
 * The beam does not show on you when you are the one who dies

**Follow the Crown**
 * Shows a blue beam that follows the group leader
 * The beam makes it easier to find and run after the leader
 * Can toggle this on/off quickly by using slash command "/crown"
 
 **Low HP Beams**
 * Shows orange beams that follow group members with low HP
 * Can change the HP threshold in the settings
 * If "Follow the Crown" is enabled, the blue beam changes to orange
 * Can toggle this on/off quickly by using slash command "/lowhp"
 
**Settings**
 * Arrow layout, color, size, opacity
 * Range limitations
 * Sound alerts when someone dies
 * Low HP threshold
