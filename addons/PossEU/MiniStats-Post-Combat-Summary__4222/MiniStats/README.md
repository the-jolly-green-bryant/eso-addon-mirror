# MiniStats — Post-Combat Summary (Console-ready)

**What it does**  
Shows a tiny overlay after you leave combat with: Fight Duration, DPS, Max Hit, and Healing Done. Disappears after ~8s. Lightweight and friendly for console.

**How to use (Console path)**  
1) Zip this `MiniStats` folder and upload it to **ESOUI** (from your phone browser).  
2) Once approved and included in the console catalog, install it from ESO → **Add-Ons**.  

**How to use (PC testing)**  
- Drop the `MiniStats` folder in `Documents/Elder Scrolls Online/live/AddOns/` and `/reloadui` in-game.

**Commands**  
- `/ministats test` → preview the overlay without fighting.

**Notes**  
- API version is set to **101046** (Update 46).  
- This MVP only tracks **your** outgoing damage/heals. Group parsing, saved history, boss tags, and a settings panel can be added later.
