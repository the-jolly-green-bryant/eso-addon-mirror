# Event Ticket Notifier

Tired of losing event tickets because you already have too many of them?
Then this addon is for you!
It will display a notification whenever you're close to maxing out your event tickets.

# Dependencies

- [LibDebugLogger](https://www.esoui.com/downloads/info2275-LibDebugLogger.html)
- LibEventData (bundled)
- [LibNotification](https://www.esoui.com/downloads/info1224-CirconiansLibNotifications.html)
