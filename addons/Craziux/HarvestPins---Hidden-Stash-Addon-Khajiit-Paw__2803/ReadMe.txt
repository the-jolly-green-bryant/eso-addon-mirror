
 This is an addon for the HarvestPins addon for the HarvestMap addon,
 that basically changes stash.dds to a khajiit paw in style with HarvestPins.
 
 
 Installation:
 Open the zipped folder MANUALLY, drop the folder "HarvestPins" into
 "C:\Documents\Elder Scrolls Online\live\AddOns" and overwrite when prompted.
 
 * If installed elsewhere, change C:\ to D:\ or E:\ etc for where your installed files are located.
 
 
 Required Addons:
 HarvestPins by: Hatory
 HarvestMap by: Shinni
