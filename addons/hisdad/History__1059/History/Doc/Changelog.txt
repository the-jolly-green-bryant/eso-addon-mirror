Version 97
For update 50
Update API Version

ESO have changed their internal data structure "Category". This relates an achievement to its description.
It is category that organises it all.

This is a small step in the right direction.

What I do when a new release is out, is to run a "dump" addon to get the achievements from the GetAchievementCategoryInfo() function call. This lets me populate the control tables in "History".

My ongoing aim is to automate this as much as possible.

I'm reviewing it all so you may see "History" lagging on new achievements even though its not "out of date"

Version 94
Internal Cleanup. Now a bit faster
It is now possible for you to prune and sort the base game dungeons to be processed.
Also the DLC modules.  DLC are getting out of hand, so you can "nope" DLC that you dont want to see.
This speeds it up a lot and stops the DLC2 tab from running off to the right.

It does not affect the data collected. You can change it back and your achievements will still be there.


This is done by editing the my/custom.lua file.  There is no GUI for this.
It will not be changed by any upgrades. An example file is provided.


In addition, the amount of data collected has been reduced, making the savedvariables/history.lua file smaller.
