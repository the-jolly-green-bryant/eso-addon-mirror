# Writcraft

**[Writcraft](http://www.esoui.com)** is an [add-on](http://www.esoui.com) for [Elder Scrolls Online](http://www.elderscrollsonline.com).

## What does it do?

1. It shows the active quest while crafting.
2. It allows you to cycle active quest while crafting.

There are crafting missions in the game called Writs.

But when you're interacting with a crafting station the mission requirement is nowhere to be seen.

There's a myriad of add-ons that helps with that, many all fancy with custom UI to show what it is you're supposed to craft.

This one's different though, it leverages the native UI of the game, simply moving, hiding or showing stuff at the right time. The overhead is the smallest possible - less code, fewer bugs - but still rich feature wise.

So if you don't want to change the game too much and likes to stay closer to the original intent this one's for you.
