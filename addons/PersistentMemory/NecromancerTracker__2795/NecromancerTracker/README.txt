Slash commands

/ntalwaysshow on -- show lefthand tracker when not in combat
/ntalwaysshow off -- show lefthand tracker only in combat
/ntalwaysshow -- toggles the alwaysshow
/ntshowmage on -- shows the mage/arcanist/archer tracker when trackers are shown
/ntshowmage off -- hides the mage/arcanist/archer tracker when trackers are shown
/ntshowmage -- toggles showmage
/ntshowmender on -- shows the spirit mender tracker when trackers are shown
/ntshowmender off -- hides the spirit mender tracker when trackers are shown
/ntshowmender -- toggles showmage
/ntshowbb on -- shows the blastbones indicator
/ntshowbb off -- hides the blastbones indicator
/ntshowbb -- toggles showmage
/ntstats -- show how many times you've summoned various things
/ntstats reset -- reset the stats
/ntall off -- just turn it all off completely, ideal for if you're not a necromancer
/ntall on -- turn back on all trackers
/ntall -- toggle all trackers. Individually. Use with caution.
/ntbbleft on -- moves the blastbones indicator to the lefthand side
/ntbbleft off -- moves the blastbones indicator back to the center
/ntbb -- toggles the left/center of the blastbones indicator
/ntleftfont [fontsize] -- change font size of the lefthand tracker
/ntleftfont -- reset to default font size for lefthand tracker
/ntbbfont [fontsize] -- change font size of the blastbones indicator
/ntbbfont -- reset to default font size for blastbones indicator
/nthumor on -- turns humor on (default)
/nthumor off -- turns humor off (boo)
/nthumor -- toggle humor
/ntbbhide -- toggle showing/hiding the blastbones indicator when combat ends regardless of if always show is on
/ntbbhide on -- turns bbhide on, hiding the blastbones indicator when combat ends regardless of always show
/ntbbhide off -- turns bbhide off

Moving the UI

While the UI is showing (may wish to use /ntalwaysshow on and /ntall on) bring up the cursor (default key .). You may then click and drag to move the indicators.

Indicators' positions are saved on a per-character basis.
