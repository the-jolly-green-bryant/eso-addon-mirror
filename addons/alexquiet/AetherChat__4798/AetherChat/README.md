A modern, immersive Chat & Messenger replacement for **The Elder Scrolls Online (ESO)**.

---

## Features

- Dedicated System Channel: Full capture of server broadcasts, queue alerts, and game status notifications with native ESO gear icon.
- Smart Escape Menu Auto-Hide: Automatically hides cleanly when opening the Escape Game Menu (Settings, Controls, Addons) and restores seamlessly upon returning to the game.
- Real-Time Typography Scaling: 12px to 24px slider with proportional scaling across the entire interface (messages, sidebar, header, search).
- Full Unicode & Cyrillic Support: Native  rendering for Cyrillic and extended international characters.
- Real-Time Loot Feed & 1-Click Need Requests (Synced with LootLog): Instant right-click context menu to request drops or ask in party chat.
- Live Guild Store Sales Scanner: Real-time sale detection even inside trials, dungeons, and combat.
- Collapsible Guild Folders: Expand/collapse your 5 guild discussions in 1 click.
- Drag & Drop Channel Reordering: Hold left-click on any channel tab to reorder your sidebar with an illuminated gold glow.
- Dedicated Whispers & High-Audibility Alerts: Unread notification badges, close buttons, and audible alerts.
- Online Friends Quick Menu: Filter online friends with character names and current zones.
- Direct Edge Resizing: Smoothly drag to adjust window width and height with persistent memory across sessions.
- Mailbox & Live Unread Badge: Direct inbox access with real-time unread mail counter.
- 5 Immersive Tamriel Themes & Full Bilingual Engine: Skyrim Dragonborn, Dwemer Gold, Nordic Emerald, Crimson Brotherhood, Dark Glass.

---

## Setup & Recommendations

1. Bind a Keyboard Shortcut: Go to Esc -> Controls -> AetherChat -> Show / Hide.
2. Hide Official ESO Chat: Go to Esc -> Settings -> Addons -> AetherChat and check Hide official ESO chat.
