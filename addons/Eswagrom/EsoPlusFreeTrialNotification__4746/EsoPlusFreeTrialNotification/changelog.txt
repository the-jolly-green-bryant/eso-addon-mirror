**1. Single Global Table (Unified Namespace)**
✅ Correctly implemented.

**2. Access Optimization (_G optimization)**
✅ Using `local EPFTN = ...` is considered very good coding style. It speeds up access to the table at the micro-level by caching the reference in the Lua stack, avoiding repeated lookups in the slow global `_G` table on every function call.
