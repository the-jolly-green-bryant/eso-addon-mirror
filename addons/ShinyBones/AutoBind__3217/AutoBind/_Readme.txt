Description:
------------
This is a simple addon designed to make it easier to bind items that are not yet unlocked in your collection.

Features:
- Quickly bind unknown items to unlock them in your collection.
- Preview window to select which items in your inventory will be bound.
- Ignored traits selection - Choose which item traits should be excluded from auto-binding.
- Optional "Bind On Collect" mode for efficient farming of set items (disabled by default).
- Optional "Bind At Vendor" mode to bind items before they leave the buyback list (disabled by default).
- Custom key bindings for quick access (not set by default).

Recommended:
- LibAddonMenu

How to use:
When the addon is initialized for the first time, it remains inactive until you interact with it.

Use the slash command "/autobind" or the corresponding key binding to open the preview window. It lists all unknown items in your inventory. For each set, the item of the lowest quality is automatically marked for binding. Hovering over an item shows a tooltip. Click an item to change or deselect it.

Use "/autobind bind" or the assigned key binding to instantly bind all uncollected items in your inventory. Only one item per type and set (with the lowest quality) will be bound.

To enable automatic binding, open the settings via "/autobindsettings".

Note: Items that are locked by the player are ignored during both listing and binding.

Key Bindings:
You can configure key bindings in-game under:
Controls -> General -> Auto Bind


See the download page of AutoBind on ESOUI for more information.
Link: https://www.esoui.com/downloads/info3217-AutoBind.html
