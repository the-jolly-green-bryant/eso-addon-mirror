Description:
------------
This addon is a tool to modify the emote data of LovelyEmotes by ShinyBones.
Open the modification menu using the chat command "/lemodifyemotedata".

See the download page of LovelyEmotes - EmoteModification on ESOUI for more information.

Requires:
- LovelyEmotes 5.0 or greater https://www.esoui.com/downloads/info1890-LovelyEmotes.html
