DecraftAll 1.0.1
==================

Fonction :
- Dans le menu de l'assistant de déconstruction (Giladil / déconstructeur universel),
  appuyez sur la touche liée à "Tout sélectionner pour déconstruire".
- Par défaut : T.
- La touche est modifiable dans Commandes > Extensions > DecraftAll.
- L'addon sélectionne tous les objets présents dans la liste filtrée actuelle.
- Il ne lance PAS la déconstruction automatiquement : la validation reste celle d'ESO.
- Les objets verrouillés par le joueur sont ignorés.
- Si FCO ItemSaver est installé, ses protections de déconstruction sont respectées.
- Les filtres ESO (onglet, banque, métiers sélectionnés) sont respectés.

Installation :
Documents/Elder Scrolls Online/live/AddOns/DecraftAll/
