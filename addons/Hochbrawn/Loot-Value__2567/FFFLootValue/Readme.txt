The FFFLootValue addon that keeps an continuous run of value of loot collected in session until reset.  Information for fun only.

To install, unzip the archive and move the FFFLootValue folder into your \Documents\Elder Scrolls Online\live\AddOns folder.  Once there, you will need to load the game and activate the addon.  Once activated, you will need to /reloadui to load the addon.

This addon uses Master Merchant if available.
