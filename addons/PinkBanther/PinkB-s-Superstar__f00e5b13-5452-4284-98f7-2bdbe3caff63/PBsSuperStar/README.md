# PB'S SUPERSTAR

PS5 / Xbox Series X|S のESOゲームパッドUIを対象にしたキャラクター情報アドオンの初期実装です。
メインメニューの **ステータス超詳細** から専用画面を開きます。外部ライブラリは不要です。

## 表示内容

- 左上タイトル：`PB'S SUPERSTAR`
- 名前、種族、クラス、レベル、CP、称号
- 装備：防具、アクセサリー、表裏武器、毒、コスチューム。選択すると品質、必要レベル、特性、付呪、耐久、武器威力・防御、チャージ、セットと各ボーナスを表示
- ステータス：基本能力、能力ポイント、APIが公開する全詳細ステータスカテゴリー、ムンダス・食事等の有効な効果
- CP：12スロット、各星座の使用・未使用ポイント、各星の投資数・上限・説明、装備中／未装備／パッシブ／未発動の区別
- スキル：表裏各6スロット、使用中の特殊バー、取得済みアクティブ・アルティメット・パッシブ、ラインランク、スキルランク、未使用ポイント。書記スキルも表示

オリジナルSuperStarを参考に、半透明の一枚の画面へ情報を配置します。左上にキャラクターと3色の基本能力、上中央に表裏2段のスキルバーと戦闘数値、左下に14部位の装備一覧、右側に3星座のポイントと装備CP、有効な効果、取得スキルを表示します。装備の特性・付呪は名前の下、セット数は右端に表示します。毒・コスチュームは装備一覧の次ページにあります。

十字キー左右で装備・詳細ステータス・CP・スキルの操作領域を選択します。装備以外の全項目一覧は右下に表示し、基本能力・装備・CPの概要を残したまま参照できます。長い一覧と説明は同じ画面内でスクロールします。省略された項目名は下部の詳細欄で確認できます。CPの色は星座の種類に対応し、装備名の色は品質に対応します。戦闘数値の「クリ値」は確率ではなくレーティングです。

## 操作

| 操作 | PS / Xbox |
| --- | --- |
| 操作領域・項目の選択 | 十字キー左右・上下 |
| 選択領域のページ送り | L1・R1 / LB・RB |
| 下部説明のスクロール | L2・R2 / LT・RT |
| 再取得 | 画面下の「再取得」ボタン |
| 未取得CP・スキルも表示 | 画面下の「取得済み / 全項目」ボタン |
| 元のメニューへ戻る | ○ / B（ゲームの戻るボタン設定に従う） |

画面表示中だけ1.5秒間隔で再取得し、閉じると停止します。数値は現在の武器バーと現在のバフを反映します。裏バーの推定ステータスや仮想ビルド計算は行いません。CPは確定済みの投資を表示します。「パッシブ」は星の種類を示し、個々の条件成立は効果説明で確認してください。スキルの取得状態とラインの有効状態も別々に表示します。

## 導入・コンソール公開

ローカルファイルの作成だけではコンソールにはインストールされません。コンソール配布にはBethesdaの開発者用Uploaderを使ったアップロード・公開手続きが必要です。このプロジェクトではアップロードや公開は実行していません。

1. PCのESO開発環境では、`PBsSuperStar.addon`、`Data.lua`、`UI.lua`、`PBsSuperStar.lua` の4ファイルを `AddOns/PBsSuperStar/` に配置します。既存のPB製アドオンと同じ `.addon` 形式のマニフェストを使用します。旧 `PBsSuperStar.txt` は同時に配置せず、配布ZIPにも含めません。
2. ゲームパッドUIで「キャラクター」と「スキル」の間にある「ステータス超詳細」を選択します。「キャラクター」の項目が見つからない環境では、従来どおりメニュー末尾に追加します。PC検証用に `/pbss` も使用できます。
3. 下記の実機チェックを完了してから、`python3 tools/package.py` で配布候補ZIPを生成します。
4. コンソール向け開発環境およびUploaderの指示に従い検証・公開します。

参考：[公式コンソールUploader案内](https://help.elderscrollsonline.com/app/answers/detail/a_id/69621/)

## 0.2.2：ロード時の負荷軽減

アドオンロード時に画面部品を生成せず、初回表示時に32ms間隔の小さな処理単位へ分けて生成します。初回は約1秒の準備時間があり、2回目以降は生成済みの画面を使います。準備中も戻る操作ができ、閉じると生成を一時停止し、再度開くと続きから再開します。

報告画像のエラーはフレーム内のアドオンCPU時間上限（1000ms）到達を示しています。スタックはゲーム標準UI内のため、本アドオンが単独の原因であるとは断定できません。今回の修正は本アドオンのロード時一括生成を取り除く対策です。実機での解消確認は未実施です。

## 実装・検証状態

API 101050 の [ESO公開API定義](https://github.com/esoui/esoui/blob/f76cf16c4e5be7b234d15dc7f676febffa64c5bb/ESOUIDocumentation.txt) と [ゲームパッドメニュー実装](https://github.com/esoui/esoui/blob/f76cf16c4e5be7b234d15dc7f676febffa64c5bb/esoui/ingame/mainmenu/gamepad/zo_mainmenu_gamepad.lua) を照合しています。参照コミットは `f76cf16c4e5be7b234d15dc7f676febffa64c5bb` です。`ZO_MENU_ENTRIES` は公開UI実装のデータ構造を使うため、ゲーム更新時には互換性確認が必要です。

`SuperStar/` は参考資料として保持しています。旧アドオンのコードや付属ライブラリーをロード・配布しません。本体は `Data.lua`（取得）、`UI.lua`（表示・操作）、`PBsSuperStar.lua`（初期化・メニュー）の3モジュールです。

ローカル検証：

```sh
luac -p Data.lua UI.lua PBsSuperStar.lua
lua tests/run.lua
python3 tools/package.py
```

Lua構文とAPIモックによるデータ・操作・メニュー重複防止・開閉時の更新停止をテストします。**ゲーム内レンダリング、PS5 / Xbox実機動作、公式Uploaderへの適合は未検証です。** ローカルテストはゲームクライアントの代替ではありません。

実機チェック：

- 新規ログイン・リロード・キャラクター切替後、メニュー項目が1つだけ表示される。
- コントローラーだけで開閉、4領域の移動、装備14行／詳細5行のページ送り、長いセット説明のスクロールができる。
- 720p / 1080p / 4KとUIスケール変更で、画面とキーガイドが切れず、日本語が表示される。
- 装備変更、武器切替、食事・ムンダス変更、スキル・CP確定後に表示が追随する。
- CP未解放、未装備、未取得、書記、サブクラス、変身バーでエラーが出ない。
- 装備・能力・CP・スキルをゲーム標準画面と比較し、一致することを確認する。
- 戻る操作で元のメニューに復帰し、閉じた後に入力や更新処理が残らない。
