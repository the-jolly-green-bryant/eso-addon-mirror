# PB’s ChatAssistant 1.16.2

1.16.2では **L2＋十字キー右専用の入力レイヤー** に分離し、旧L2＋L3の入力レイヤーを起動時に解除します。L3のバインドやチャンネル切り替え処理は登録しません。

同時押し中は標準のクエスト切り替え（`ASSIST_NEXT_TRACKED_QUEST`）を遮断します。L2の防御と、L2を押していないときの右の通常操作は維持する構成です。

ESOコンソール版のチャット入力補助と、HUDでの投稿先チャンネル切り替え。

**戦闘中はL2＋右による投稿先切り替えを無効にします。** 戦闘開始時に右の入力レイヤーとクエスト切り替えの遮断を解除し、戦闘終了後に再開します。

## HUDでの切り替え

1. チャット入力画面を閉じ、通常のHUDに戻ります。
2. **L2を押したまま十字キー右を押します。**
3. L2を保持したまま十字キー右を押すたびに、次の投稿先へ切り替えます。
4. L2を離すと、十字キー右の通常操作へ戻ります。

L2はバインドせず、押し込み量を読みます。PBsScreenshotModeShortcutと同様に、防御状態も補助判定に使います。L2が標準の防御割り当てであることを前提にしているため、防御を別キーへ変更した場合はそのキーでの防御中も反応します。

右の入力レイヤーとクエスト切り替えの遮断は、L2保持中だけ有効です。同時押しとして右を押した後は、L2を先に離しても右の解放処理が終わるまで保持します。右のリピート通知による連続切り替えは防ぎ、押し直すたびに次の投稿先へ進みます。

L2を少し先に押してから右を押してください。入力レイヤーの更新周期は10msで、実際の反映はゲームのフレーム更新にも依存します。L2を押した瞬間と完全に同じフレームに右を押した場合の捕捉は保証できません。

文字入力画面、メニュー、Enter捕捉中は切り替え用レイヤーを外します。エリア移動・コントローラー切断でも解除し、復帰後に再開します。入力解放の通知が欠落した場合は、右の保持状態を5秒で解除します。L2自体の保持には時間制限を設けません。投稿先はチャットログに表示します。

**今回のL2＋右とクエスト切り替え抑制は実機未確認です。** `lua test/hud_channel.lua`で入力状態とXMLの回帰テストを実行できます。更新後は「L2単独の防御」「右単独のクエスト切り替え」「L2＋右で投稿先のみ切り替わる」「L2を先に離してもクエストが切り替わらない」「L2＋左のスクリーンショットモードとの併用」を確認してください。

## 設定

設定 → アドオン → PB’s ChatAssistant

| 項目 | 内容 |
| --- | --- |
| L2＋十字キー右で投稿先を切り替える | HUDでの切り替え機能のON/OFF（`/pbchat hudchannel` と同じ） |
| ログイン時の投稿先 | セッション開始時の投稿先。「変更しない」で無効 |
| 開くまでの待ち時間 | 文字入力画面が出るまでの待ち時間 |

「ログイン時の投稿先」の選択肢は**パネルを開くたびに作り直します。** アドオンのロード時点では
ギルド所属が確定しておらず、ギルド名の代わりに `/g1` のようなコマンド表記になったり、
そもそも一覧に出なかったりするためです。

適用はログイン後の数秒後に一度だけです（ギルド所属の確定を待つための遅延）。
エリア移動やロード画面を挟んでも再適用しません。使用できないチャンネルは適用しません。

## コマンドと診断

- `/pbchat hudchannel off` / `on`：HUDショートカットを停止・再開。
- `/pbchat entrychannel off` / `on`：互換用の別名。新しいHUDショートカットへ適用します。
- `/pbchat hudstatus`：L2の読み取り値、十字キー右の受信回数、レイヤー状態、エラーを一度だけ表示。
- `/pbchat binds`：実際に宣言している十字キー右アクションと継承元を表示。
- `/pbchat forcelayer`：旧強制モードは廃止。通常操作を妨げるレイヤーを強制維持しません。
- `/pbchat safe`：既存のEnter捕捉を停止してコントローラー操作へ戻す。

以前の試行でHUD切り替えを無効にした保存設定とは別の `hudChannelEnabled` を使い、今回の新機能は初期状態で有効です。
アドオン全体のオフ設定やEnter捕捉設定は維持します。

## チャット入力補助

コントローラーで通常どおりチャットを開いたときに、本体の文字入力画面を出す既存の監視処理を維持しています。
Enterで開きたい場合は `/pbchat enter` で捕捉を有効にします。
設定 → アドオン → PB’s ChatAssistantから、入力画面を開くまでの待ち時間を調整できます。

## 導入

LibHarvensAddonSettings（20106以上）が必要です。
旧フォルダを更新版で置き換え、`/reloadui`または再ログインしてください。更新後はアドオン一覧のタイトルで1.16.2を確認してください。旧版やPBsHUDChannelProbeなどの別アドオンが同時に有効なら、それらの割り当てはこの変更では削除されません。
ZIP内のPBsChatAssistantフォルダを使い、別のPBsHUDChannelProbeは無効にしてください。
元の配置ソースは `PBsChatAssistant-1.13.1-source-backup.zip` に保存しました。
