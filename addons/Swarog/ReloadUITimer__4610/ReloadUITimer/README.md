# Reload UI Timer

Measures actual ReloadUI duration and prints the result to chat.

Example:

[ReloadUITimer] ReloadUI took 13.842 s

## Features

- Measures real ReloadUI duration
- Automatic output to chat
- Localized chat message
- No settings
- No dependencies
- Minimal overhead

## Notes

There are intentionally no settings.
To disable chat output, simply disable the addon.
