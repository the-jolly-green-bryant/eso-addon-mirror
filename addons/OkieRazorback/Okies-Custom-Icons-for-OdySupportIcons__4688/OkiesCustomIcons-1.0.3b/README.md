# OkiesCustomIcons

OkiesCustomIcons is an icon pack for the OdySupportIcons addon (Elder Scrolls Online). It supplies custom icon assets and mappings that OdySupportIcons can use to display alternate visuals in the UI.

Installation
- Place the `OkiesCustomIcons` folder in your ESO AddOns directory.
- Ensure the `OdySupportIcons` addon is installed and enabled.
- Restart the game or reload the UI (`/reloadui`).

Files
- `OkiesCustomIcons.lua` — main addon script
- `OkiesCustomIcons.addon` — addon manifest
- `icons/` — icon assets (DDS files)
